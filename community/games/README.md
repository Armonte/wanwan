# Game table

`game_table.tsv` is generated by fm2k-port `tools/community/gen_game_table.py --format tsv` from the fm2k-catalog
join; regenerate it, never hand-edit it. `game_table_extra.tsv` holds builds the catalog does not know yet (one row
per `.kgt` SHA-256), with the rules copied from a known build of the same game. Import both, the generated one first:

    python3 admin.py import-games games/game_table.tsv
    python3 admin.py import-games games/game_table_extra.tsv

| extra build | why |
|---|---|
| wonderfulworld `54873cd1...` | WonderfulWorld ver 0946, the build the old hub's 2634 matches were played on; rules from the 0945 row |
